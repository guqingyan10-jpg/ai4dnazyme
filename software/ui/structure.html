About the coordinate viewer
This viewer renders supplied coordinates; it does not run AlphaFold or predict a structure. Backbone lines are visual guides rather than validated covalent bonds. Only the first model and the preferred alternate location are shown.
B-factor values are interpreted as pLDDT only when explicitly confirmed. Coordinate coverage and prediction confidence are separate from RNA accessibility and do not affect candidate ranking.

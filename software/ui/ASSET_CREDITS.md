# Frontend artwork

The Zyme mark and recognition-window illustration in `assets/` were created
for this project as editable SVG artwork. They are part of this repository's
MIT-licensed original code/assets. The recognition image is a conceptual
diagram, not calculated molecular coordinates or experimental evidence.

The interface uses installed system fonts. It loads no web font, icon library,
CDN, tracking script or third-party template. Barcelona-UB's 2025 software page
was consulted for the separation of user-facing access, documentation and
developer interfaces; its source code, branding and artwork were not copied.

Third-party computational components retain their own licenses; see the
repository's THIRD_PARTY_NOTICES.md. The code license does not replace the
license requirements of the team's published iGEM Wiki.

FOR THE FIRST-TIME USER

Use the desktop application

  1. Download the complete Windows bundle from the software's release repository. Extract the ZIP; keep its files together.
  2. Open ZymeSiteDesigner.exe. Choose a FASTA transcript or paste its sequence in Transcript.
  3. In Design, set the cut motif, left and right arm lengths, and folding settings. Supply a reference FASTA for off-target screening.
  4. Select Run analysis. When it completes, open the generated report or load result.json in this workspace.

The portable build includes its computational runtime. No cloud account, GPU or server is needed. This page does not download or execute the desktop application.

FOR REPRODUCIBLE WORKFLOWS

Use Python & the command line

In the source-project folder, use Python 3.10 or later:

python -m pip install -e ".[desktop]"
python desktop_entry.py

A folding analysis without a reference screen:

python -m zyme_designer design --target-fasta examples/BIRC5_NM_001168_3.fasta --gene BIRC5 --left-lengths 7,8,9 --right-lengths 7,8,9 --motif AG --fold --fold-backend python --temperature 37 --window 200 --span 150 --out results/my_design

Choose a new output folder for each run. Add --transcriptome and a versioned --reference-label to evaluate reference matches. The reference library is not bundled.

WHAT TO BRING INTO THIS WORKSPACE

One result. Several ways to explore.

result.json contains the target, candidates, match records and analysis metadata. Use Open results; files are parsed locally, not sent to a server.

Search or sort the candidate library. Select a point or table row to inspect that design. Export the selection as CSV or FASTA, or export all filtered records.

Structure viewer opens your PDB or mmCIF coordinates. It does not run AlphaFold. A chain-mapping JSON can highlight a recognition region.

START WITH THE RIGHT COMPARISON

Read the evidence, not just the score.

Arm length is a trade-off: short arms may lack specificity; long, tightly bound arms can complicate product release. Inspect the actual lengths, binding estimates and screening results together.

Use the AG preset for the project's 8–17 design, or define another dinucleotide motif. A custom motif is a design constraint, not a guarantee that another catalytic core will cleave it.

A missing screening result is not zero off-targets. An accessible window is not a measured cleavage rate.

About the BIRC5 example. It is a saved program run, not a new calculation performed by this webpage. Its small demonstration reference is explicitly not the human transcriptome. The run's actual scope and missing fields remain visible in the workspace.
